# Проектирование хранилища данных: витрина выручки по категориям

Отчёт: [report.md](report.md)

## Данные
Набор данных E-Commerce Sales and Customer Analytics:
https://www.kaggle.com/datasets/datascikhan/e-commerce-sales-and-customer-analytics

Скачайте CSV и положите их в папку `data/` рядом со скриптами (в репозиторий они не входят).

## Структура
- `report.md` отчёт
- `diagrams/` схемы (draw.io и PNG)
- `scripts/profile_data.py` скрипт первичного профилирования
